현장 촬영앱

현장 인원 · 휴대폰 전용
  • GPS 위치·나침반 방향·촬영시각 자동 기록
  • 사진·영상(30초) 촬영 후 즉시 전송
  • 통신 불량 시 임시저장 → 자동 재전송
🗺️

중앙통제실

상황실 PC·태블릿 / 현장지휘 휴대폰
  • 촬영위치·방향선 실시간 지도 표시
  • 방향선 교차로 화점 후보 자동 계산
  • 산불영역 작도·면적 산출·확산 추이

운영 순서

  1. 통제실 [현장앱 배포]에서 사건코드를 정하고 QR·주소를 현장 인원에게 전달
  2. 현장 인원은 주소(QR)를 열고 [아래 내용에 동의하고 촬영 시작] → 산불을 십자선에 맞춰 촬영·전송
  3. 통제실은 방향선·화점 후보와 사진을 보고 [산불영역 그리기]로 시각별 영역 저장
  4. 면적·확산속도 추이로 상황 판단 (2차: 기상 연계 확산 시뮬레이션)
